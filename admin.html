自動比對說明

後台會自動呼叫 GitHub API 比對 games/ 資料夾下的所有子目錄與 games.json 的資料。

若發現有子目錄（例如：games/my-new-pico-game/）存在，但 games.json 中沒有 id 為 my-new-pico-game 的項目，系統會將其判定為新遊戲，自動在左側產生一個預設標題為資料夾名稱的編輯表單。

填妥介紹與操作說明後，點擊該表單底部的「儲存此遊戲」按鈕，即可寫入設定檔並完成線上發布！
